Réseau de points de vente

Exemple de Store Locator : La carte ajuste automatiquement son zoom et son centrage pour inclure tous les marqueurs du tableau de données.

// La bibliothèque utilise fitBounds() automatiquement dès qu'il y a plus d'un marqueur
const map = new MagixMaps({
    api_key: 'VOTRE_CLE',
    markers: [
        { company: "Huy", lat: 50.52, lng: 5.24 },
        { company: "Liège", lat: 50.64, lng: 5.57 },
        { company: "Namur", lat: 50.46, lng: 4.86 }
    ]
});
